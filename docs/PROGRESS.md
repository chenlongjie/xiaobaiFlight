## 一、项目概述

`flight-real` 是从 wet-paint 手感壳改造来的**自由世界飞行游戏**，核心玩法 = 在山谷/海面间自由飞行 + 多用户同时在线互见。采用**客户端权威 + 零依赖 WebSocket 中继**架构：

- 每个客户端自己算物理（确定性哈希噪声世界），本地手感零延迟；
- 中继服务器只做"转发玩家状态"，不存地形、不跑物理、无任何三方依赖；
- 上线形态：**Netlify 静态托管页面 + 一台独立 Node 中继服务器**，无需数据库。

## 二、已实现功能清单

### 1. 飞行核心（继承 wet-paint 手感，最不该重写的部分）
- 压坡度转向（A/D）、爬升/俯冲（W/S）、加速（Shift）、惯性、贴地抬升、追尾相机；
- `Space` 单击切换 **悬停 / 继续**：悬停时速度平滑衰减到 0、不掉落，HUD 徽章"飞行中"（绿）/"悬停中"（琥珀）；
- 悬停中按 `A/D/W/S`（或手柄摇杆）**上升沿解锁直接起飞**——仅"从无输入突变为有输入"才解锁；刚进入悬停时的输入记为基线（按住 W 按 Space 不会误起飞），恒定摇杆漂移不误触；
- 悬停中**鼠标/触摸拖拽环视**：绕玩家自由转视角（水平无限、俯仰 ±66°），只转镜头不转玩家；恢复飞行时自动平滑回追尾。

### 2. 联机（本轮新增）
- `server/server.mjs`：零依赖 WebSocket 中继，端口 8791；
  - 握手：新连接收到 `welcome {id, peers}`，其余玩家收到 `peer_join`；
  - 转发：`state [x,y,z,yaw,pitch,roll,speed]` 广播时排除发送者；
  - 清理：90s 无任何消息（含 20s 心跳 `{"t":"hb"}`）即断开；
- `src/net.js`：客户端同步层；
  - 15Hz 状态上报；远程玩家**阻尼插值**（首帧跳变到真实位置）、yaw 归一化插值；
  - **心跳独立 `setInterval`**，不受后台标签页 rAF 暂停影响（修复过被服务器 90s 误踢的问题）；
  - 掉线自动重连，HUD 四态文案：`· 在线 N 人` / `· 连接中…` / `· 已断线，自动重连…` / `· 服务器连接失败`；
  - 远程玩家挂名字标签（depthTest 关闭，远距离可见）。
- `serve.mjs`：静态服务器修复——目录请求 301 补斜杠并保留 query、自动补 `index.html`（`/?name=2` 可直接打开）。

### 3. 世界
- 确定性生成：哈希噪声地形/水/岩块/植被/天空，所有客户端看到同一世界，服务器无需同步地形。

## 四、运行方式

```bash
# 中继
node server/server.mjs 8791
# 静态站点
node serve.mjs 8714
# 开两个页面（联机）
http://127.0.0.1:8714/?name=2
http://127.0.0.1:8714/index.html?name=测试二号
# 冒烟测试（需中继在跑）
node server/smoke-test.mjs
```

上线：**仓库根**部署到 Netlify（入口 `index.html`）；中继单独跑一台 Node（`server/server.mjs`），前端通过 `?ws=ws://中继地址` 开启联机。

## 六、后期展望（Roadmap）

### 近期（性价比最高）
1. **部署落地**：写一份 Netlify + 中继的部署脚本/说明（含 `?ws=` 默认地址配置），真正跑起来让朋友能一起玩。
2. **断线重连体验**：重连后若同 id 先发 `claim`，把旧连接顶掉（防攒幽灵连接）；HUD 增加"最后存活提示/RTT 显示"。
3. **移动端触控**：虚拟摇杆 + 双指拖拽环视（现有 pointer 逻辑已兼容触摸，补 UI 层）。

### 中期
4. **房间/大厅**：?room=xxx 隔离频道，玩家列表可视，支持邀请链接；中继按房间分表转发。
5. **观战与跟随**：死亡/掉线后可自由相机观战其他玩家（复用悬停环视的轨道相机）。
6. **聊天/表情**：中继转发文本帧（低频率、长度限制、防刷），HUD 气泡。

### 远期
7. **玩家账号与昵称持久化**：localStorage 昵称 + 头像选择，中继按玩家 id 记录在线时长。
8. **服务器权威扩展点**：若需要防作弊/排行榜，抽"权威模式"：物理双跑（客户端展示 + 服务器仲裁），当前确定性世界为此预留了条件。
9. **世界扩展**：多岛屿/塔楼/洞穴等可交互地标，并设计"检查点/竞速赛道"玩法，配合排行榜。

### 已知限制（技术债）
- HUD 在线人数只统计"其他玩家"，多人时易被误读；
- 中继单进程无集群/房间上限，百人级需分片或加房间隔离；
- 无认证，昵称可重复（显示时以 id 区分即可）。
