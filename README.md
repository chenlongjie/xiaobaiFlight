# 小白乱飞，自己拿去改

## 跑起来

```sh
cd flight-real
node serve.mjs 8714
# 打开 http://127.0.0.1:8714/
```

| 键 | 作用 |
|---|---|
| A / D | 压坡度转向 |
| W / S | 爬升 / 俯冲 |
| Shift | 加速（目标速度 42） |
| Space | 收风 / 下潜 |
| C（长按） | 切环绕机位，看画面用 |

URL 参数：

- `?look=1` 固定机位俯瞰峡谷（构图对比用，不飞行）
- `?q=low|mid|high` 画质档（默认 mid）
- `?res=384` 地形格数（默认 384，即 900 单位 / 384 ≈ 2.3m）
- `?grass=30000&bushes=6000` 实例数量
- `?flowers=20000` 花丛簇数（默认 low 8000 / mid 30000 / high 52000，远景粉色植被由地形贴图自带）

## 这一版换掉了什么

| 层 | wet-paint | flight-real |
|---|---|---|
| 材质 | 自写 painted shader，纯顶点色 | **MeshStandardMaterial + 三平面投影贴图**（GGX + 环境反射） |
| 环境光 | 廉价半球光 | **程序化 HDR 天空 → PMREM → scene.environment（真 IBL）** |
| 贴图 | 无 | 岩壁/草皮/法线/草叶/树冠/水面法线，全部 canvas 现画（仍零外部资产） |
| 地形 | 缓坡花海 | 蜿蜒河道 + 两侧 **竖向沟壑崖壁（约 80°）**；外圈噪声海岸线，山体沉入海面 |
| 植被 | 6 个圆锥的草簇 | 草 + 灌木两层交叉卡片；贴图暗橄榄色，实例色只做近白微变化（避免荧光绿） |
| 山体 | 光滑缓坡 | 扶壁/冲沟 + 碎石带；岩面**无重复纹样**（各向同性 ridged 噪声派生反照率/法线/AO，三平面加权采样） |
| 水面 | PBR + 天空反射 | 双层法线：**20–60m 大褶皱（保留到远景）+ 2m 细纹（远处收掉）**；1000² 深度图驱动浅滩透光；掠水尾迹翻白 + 水珠飞溅 |
| 后处理 | 纸纹 / 水彩 / 铅笔线 | **HDR 半浮点 → 亮部提取 → 分离式模糊 → ACES + 分级 + 暗角 + 颗粒** |
| 飞行手感 | — | 原样保留 `flight.js`（压坡度转向、惯性、贴地抬升、追尾相机） |

## 大气与手感

- **高度雾**（`src/fog.js`）：密度随海拔指数衰减（谷底浓、山顶清），雾色朝太阳方向转暖（前向散射）。
  替换掉原来的均匀 `FogExp2`，远景才有层次。
- **速度感**（`src/fx.js`）：风线（相机局部空间的短线束）+ 花瓣粒子 + 相机微抖，强度都挂在速度上。
- 岩壁贴图**刻意不含任何"格"结构**：Voronoi 块面会像龟壳，水平层理会变等高线。方向感交给几何。

## 世界结构

`半径 ≈350m` 以内是一整块山体（峡谷切在其中），外圈用噪声海岸线沉入 -16~-26m 的海床。

**谷口海湾**：往 -Z 飞（开局朝向），`z≈-240` 之后谷底整片沉入海面，形成约 400×600m 的开阔水湾，
再往外接海岸线与外海。湾里立了 4 根海蚀柱（高出水面 20~29m）作为速度参照物。
海面是一块 9000×9000 的平面，**每帧跟随相机**，所以永远看不到边缘；
雾色 = 天空地平线色（`0xcfd9dc`），远处海面和山会直接"化"进天空里。
飞行边界放到 540，可以飞出海岸线一大段再被引回。

## 性能说明

高度场只求值一次（`buildField`），地形网格 / 水深图 / 撒点 / 飞行碰撞全部复用同一份采样，
首屏约 3~4 秒（含全部程序化贴图生成），之后是纯 GPU 开销。

## 文件

```
src/main.js     起飞顺序：渲染器 → 天空/IBL → 地形 → 水 → 植被 → 骑手 → 后处理
src/terrain.js  高度场（纯函数，飞行碰撞共用）+ 水面
src/mat.js      三平面 PBR 材质（注入 three 的 MeshStandardMaterial）
src/tex.js      程序化贴图（canvas，零外部资产）
src/sky.js      HDR 天空 + PMREM 环境光烘焙
src/veg.js      草/树交叉卡片实例化 + 风
src/post.js     HDR 后处理链
src/flight.js   飞行壳（原样搬自 wet-paint）
src/rider.js    女巫 + 黑猫 + 扫帚（基本几何 + PBR）
```
